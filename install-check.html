Chic — install diagnostics

Open this page in Chrome at the same URL you use for the app. Every row must be green before Chrome replaces “Create shortcut” with “Install”.

If every row is green but the button stays disabled, the app is probably already installed. Check chrome://apps, remove “Chic”, then reload.

Installed, but the icon has a Chrome badge?

Then Android made a shortcut, not a real app. Every check above can pass and this still happens — the last step is out of the page’s hands.

Chrome does not build the app itself: it asks Google Play Services to mint a “WebAPK” and install it. When that fails or is unavailable, Chrome silently falls back to a plain home-screen shortcut, which keeps the Chrome badge and opens in a tab with the address bar showing. A real WebAPK has no badge and opens with no address bar.

To find out which you got, open chrome://webapks — a real install is listed there. If the list is empty, work through these in order:

  1. Google Play Store must be enabled. The minted APK is installed through the Play Store, so a disabled Play Store breaks the install even though Play Services itself looks healthy. Settings → Apps → Google Play Store → Enable.
  2. Google Play Services enabled and updated.
  3. Android Settings → Apps → Special access → Install unknown apps allows Chrome.
  4. Delete the badged icon before retrying, and stay on a good connection — minting needs a server round-trip and falls back to a shortcut if it times out.
